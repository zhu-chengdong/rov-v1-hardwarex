# Hardware design source

All eleven listed custom parts, associated nominal exports, five manufacturing review drawings and project wiring diagrams are covered by CERN-OHL-P-2.0. Copyright 2026 Chengdong Zhu and contributors. See ../LICENSES/CERN-OHL-P-2.0.txt.

Native 2018 part geometry is retained. The 2024 review subdirectory contains its own five unchanged model copies for drawing references. Preserve that subdirectory structure. Supplier reference assemblies and electronics/component models are excluded. These files do not change the robot design.

Units are millimetres. Six DXFs contain 68 circular holes; the separate five-drawing coordinate table counts 48 circles plus 20 slots. They are different sets. Unapproved tolerances and acceptance requirements remain open. Materials and real installation follow ../docs/build_and_operation.md and ../docs/BOM.csv, not generic material properties embedded in reference CAD.
