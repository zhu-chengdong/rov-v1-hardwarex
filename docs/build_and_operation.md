# V1制造装配与维护说明

内部5 mm亚克力组件按DXF激光切割，包括相机支架1件、圆弧侧支承2件、主板1件及中间层1件。SLA外框包括后上支板2件、后下支板2件、侧边挡板2件、底板1件和盖板1件。供应商完成打磨，未选择金属螺纹嵌件，历史批次不统一指定9000HE。五张R1图和本包名义孔槽表分别使用，补充配合说明见manufacturing_fit.md。

前后端盖均Ø220×8 mm亚克力，前盖无中央孔。每端8个Ø6通孔配M5×45紧固件，后盖另有10×Ø10.2安装孔及中央Ø12.2孔，分别对应8个M10空心、2个封堵和中央M12空心穿线件。舱体、前后盖、O-ring和全部开孔费用含在C01中，继续使用商购配套密封结构。

内部圆弧支承和相机支撑合计6套M4×30连接，采用螺栓螺母，圆弧支承接头有胶粘。中间层4根M3×45母母铜柱、相机8组M2.5×10公母铜柱、可选IMU3组M2.5×15公母铜柱，明细见fasteners.csv。竖直T6用M4×20及垫片，水平T6用M4×25，灯夹用M5×25，侧板与底板4处用M5×35。六推进器直接固定框架，灯夹随灯附带。

Jetson通过亚克力支架和可移除双面胶固定，两电池和正负铜排底座粘贴载荷板，Pixhawk贴6S电池，PM02由线束约束。载荷架由圆弧支承贴筒体，少量热熔胶辅助限位。原套件排线与后来另购22P、0.5 mm、20 cm反向异面FFC分开记录。拼接图左半幅对应左相机。

穿舱处用胶枪施加MF-01 AB胶，通常灌封后第二天下水，保留厂家混合后三分钟内施工的同型号说明。纸巾清洁密封面，硅脂定期维护，端盖对角交替分轮逐步紧固，扭矩未记录。以工作面承托抽出的载荷架，保留线缆松弛余量。

归档17块名义100 g铅块以螺钉固定在底板17孔，后来未带至英国，不视作所有运行均采用的配重。未指定的一般公差和未记录的历史小件不补造；图纸保留审阅状态。
