# V1制造装配与操作

## 制造与数量

内部5 mm亚克力按DXF激光切割，相机支架一件、圆弧侧支承两件、最大的板子一件、中间第二层一件。双目相机使用同档位的对称孔组，名义80/100/120 mm；机械孔距与水下标定外参分别登记。

外框SLA打印后上支板两件、后下支板两件、侧边挡板两件、底板一件、盖板一件。供应商完成打磨等后处理，未选择金属螺纹嵌件。至少一笔订单为9000HE白色树脂，其他批次未知。四圆弧件相互螺栓螺母连接，与侧板及底板的垂直连接用较厚板件中的普通螺母定位。六T6直接固定在框架，两WL-1500用随灯夹具固定在框架槽位。

前后盖为Ø220×8 mm亚克力，前盖无中央孔；每端8×Ø6通孔配M5×45螺栓。后盖另有10×Ø10.2和中央Ø12.2孔，对应8个M10空心、2个M10封堵及M12以太网空心穿舱件。匹配筒体为OD180×400 mm，舱体及密封件商购。公差、完整紧固件数量和独立替换O-ring规格待补，CAD名义值不作为制造验收值。

## 灌封与内架

穿舱件依靠自身密封压紧结构，再用配套胶枪施加VIOCEAN MF-01 AB胶二次灌封九个空心件，通常隔日下水，不把它作为验证的最短固化时间。以太网裸线穿舱后再压接内外两个RJ45。胶型说明、混合配比及适用固化条件尚需同型号产品说明核对。

Jetson采用亚克力支架及可移除高粘双面胶，两电池贴在亚克力载荷板上，Pixhawk贴在6S电池上方，两根铜排底座粘贴于板上。PM02不另设机械固定，靠连接线束约束位置。载荷架圆弧侧支承贴合筒体，依靠自重、接触摩擦及少量热熔胶辅助限位。其他胶接处未指定同一种胶材。

相机排线与Jetson随载荷架移动，后盖线束留余量。移动时由工作面支承，避免以线束吊挂。实装CSI组合及部分间距/连接件规格待核。归档17块名义100 g铅块螺钉固定底板17孔，后来未带至英国；不把这一配重数量写成所有试验构型。

合舱前一般纸巾擦净O-ring和接触面，不用专用清洁剂，硅脂定期涂抹而非每次。后盖8螺栓对角交替分轮逐步紧固，未记录扭矩。更换相机位置或镜头/前窗关系后按最终装舱状态标定。

## 使用与结束

平台用于人工监护浅水研究，通过手柄映射控制运动。两灯分别接PWM7/8，在QGroundControl中手动输入数值分别调节亮度。没有把未实现的手柄灯光按键写作现有功能。

结束时作者先拔手柄减少误触，再由PC远程停止采集节点和数据记录、关闭Jetson，并看指示灯熄灭。随后用牵引绳回收、抱上岸、开后盖，分别拔下6S XT90和Jetson圆形DC实现物理断电，再移动载荷架。拔手柄不是已验证急停，指示灯观察不替代bag文件收尾检查。初始接电先后、解锁及失联处置尚无完整记录。
