# 实装供电与信号连接

6S GNB 6500 mAh通过XT90接入正负各一根8位M5铜排。每根铜排一位接输入，六位对应六个T6动力支路，余下一位供两灯和PM02辅助分支。PM02使用商购配套线连接Pixhawk POWER口，不新增自制逐针线序。当前未启用6S电压/电流监测、低压报警或自动切断，未安装主支路保险或外部主断电。

4S HRB 6000 mAh经EC5-to-XT60和XT60-to-DC5.5×2.5 mm直接供Jetson官方载板，链路无外置DC/DC。两输入通过串口公共参考地连接，不作电气隔离描述。实际DC极性及部分主支路线规和端子规格仍未完整登记，不能把功能示意图直接当作逐针通电图。

FT232RL的USB接Jetson，UART接Pixhawk TELEM1，TX/RX交叉且接GND，VCC不接。MAIN OUT 1—6用于六个推进器，7/8用于两灯。推进器使用三芯PWM/舵机延长线，仅使用信号芯，保留Pixhawk端插头、截断另一端后与集成ESC信号线连接，原正负两芯剪除。推进器动力正负线仍接6S铜排，既有连接提供公共参考地，各路PWM没有另拉地线。这是本机接法，不是通用无需参考地规则。

1—6的实物位置与旋向、7/8的物理左右灯对应仍待核。当前公开图按功能分组，不按默认布局猜测。图中的TELEM泛称应结合本文的TELEM1实装确认读取。
