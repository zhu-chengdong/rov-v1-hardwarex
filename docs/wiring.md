# 供电接线与八路输出

6S 6500 mAh电池通过XT90母头10 AWG成品输入线接正负8位M5铜排。六个T6和两盏WL-1500的电源经16 AWG延长，线间绞接、焊接并热缩覆盖，以M5环形端子接铜排。PM02使用配套线接Pixhawk POWER口，相关XT60电源线为14 AWG附电容成品线，两者分开记录。

4S 6000 mAh电池通过EC5-to-XT60和XT60-to-DC5.5×2.5 mm兼容成品线直入Jetson官方载板，中心正，无外置DC/DC。两路通过串口参考地形成公共参考。当前主支路保护和低压自动切断未安装，实际断电在开后盖后分别拔6S XT90和Jetson圆形DC。

FT232RL为3.3 V TTL，经USB接Jetson，UART侧只接RX/TX/GND到TELEM1，VCC不接。推进器PWM延长线只保留信号芯，原正负芯剪除，公共参考地沿既有连接建立。PM02配套POWER线不另要求拆解内部线序。

MAIN OUT 1右前、2左前、3右后、4左后、5右垂直、6左垂直；7左灯、8右灯。左右按机器人朝前方向定义，具体桨型组和端接见output_mapping.csv。

以太网系缆为5 m防水无屏蔽Cat5线，两端均T568B，使用Cat5e RJ45接头。没有屏蔽层、排流线或金属屏蔽壳。后盖M12内部通孔8.5 mm与安装孔12.2 mm分别记录，不把通孔径当作适配电缆外径。
